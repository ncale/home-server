# Home Server

Personal homelab running on a single-node Proxmox server. Self-hosts media, private storage, home automation, and local network services.

## Structure

- `docs/` — Proxmox setup, VM/LXC layout, and network configuration
- `stacks/` — Docker Compose files for services deployed via Portainer
